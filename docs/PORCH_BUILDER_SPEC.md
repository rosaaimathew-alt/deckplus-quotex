# Porch Builder — working spec

Notes captured while Deck Plus explains how porches are priced. Rules here are
the source of truth for the porch tool; the code follows this file. Anything
marked **?** is still an open question.

## Primary cost drivers (in order)
1. **Size** — width × depth of the porch.
2. **Roof connection** — how the porch roof ties into the house.
3. **Structure / floor** — what the porch sits on (existing slab, existing
   deck, new deck framing, new slab, …).
